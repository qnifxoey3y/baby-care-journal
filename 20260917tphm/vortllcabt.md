# 新突破|青大附院泌尿外科成功开展国内首例PercuNav超声融合成像导航定位引导下骶神经刺激电极植入术

> 更新时间：2026-09-17 (UTC+8)

//  

近日，我院泌尿外科在牛海涛教授、李延江教授的指导下，利用PercuNav超声-CT融合成像导航技术成功开展国内首例超声融合成像导航定位下骶神经刺激电极植入术。

本次手术由泌尿外科马晓诚主治医师、腹部超声科郑曙光副主任医师共同完成，术前将超声与CT影像进行精准定位匹配融合，术中通过超声定位引导穿刺效率显著提升，术中测试应答良好，术后X线评估电极植入位置精准，手术顺利，仅用半小时。

既往骶神经刺激电极植入术主要单独依靠X线定位，该方式定位精准度较高，但手术时间长，需要反复透视，对医生和患者有较大辐射危害；目前国内相关领域专家，都在积极地探索新型定位方式，包括超声定位、3D打印、AR/MR技术等。PercuNav超声-CT融合成像导航技术已成熟应用于肝脏等脏器病变的穿刺，但在骶孔穿刺应用方面鲜有报道。超声融合成像导航定位方式，可以在保证穿刺定位精准度的前提下，减少X线辐射危害，提高穿刺定位效率，减轻患者痛苦，缩短手术时间。PercuNav超声融合成像导航技术的成功应用，是我院泌尿外科联合腹部超声科在骶神经刺激电极植入手术的新突破，是超声融合成像导航技术应用的新拓展，标志我院在骶神经调控手术应用、在尿控领域疾病治疗上达到新高度。

**骶神经调控术（SNM）**

骶神经调控术（SNM）是利用介入技术将低频电脉冲连续施加于特定骶神经，以此兴奋或抑制神经通路，调节异常的骶神经反射弧，进而影响并调节膀胱、尿道/肛门括约肌、盆底等骶神经支配靶器官的功能，从而达到治疗效果的一种神经调节技术。

SNM是治疗多种下尿路功能障碍的有效方法，目前在国内越来越普及，因其可以改善下尿路症状、提高生活质量、没有毒副作用等优势，受到了越来越多的关注。SNM的适应症包括难治性膀胱过度活动症、非梗阻性尿潴留和大便失禁。我国专家将SNM探索性应用于神经源性下尿路功能障碍、间质性膀胱炎/膀胱疼痛综合征及其他排便功能障碍，也取得了令人满意的效果。
